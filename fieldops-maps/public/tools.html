Analysis and map components

Tools run in your browser. Analysis creates a new, unsaved layer; use its Save button to keep it. Source layers stay unchanged. Analysis uses complete layer data, including features hidden by personal filters.

WGS84, Web Mercator, WGS84 UTM and Australian MGA grids; rotated grids need reprojection first. This is not a survey datum transformation.

Analysis accepts up to 20,000 input features in total, with tighter pair-count limits for intersections and point counts. Cancel closes the dialog and terminates the analysis worker. Very complex geometry may still need smaller batches. Polygon overlay assumes ordinary local map geometry; split datasets crossing the antimeridian before processing.

Components

Add statistics, bar charts, histograms, numeric line charts and daily time series. Choose count, sum, mean, minimum or maximum where applicable. Missing or invalid numeric values are excluded. Time series uses UTC dates.

Lists, sliders, single-select and multi-select controls filter their selected layer. The map, table, charts and exports use those filters. Different controls combine with AND. Multiple selections within one control use OR. A slider sets a minimum value. The Filter tool opens the existing multi-condition attribute filter.

Up to 12 components are saved per account and project in this browser. They are not shared dashboards, cloud-synced layouts or operator defaults. Removing a filter component clears that component's filter. Charts show up to 40 groups, with up to 500 values in the accompanying table. Selection controls list the first 500 distinct values. Components are not part of print layouts.

Drawing and uploads

The compact toolbar opens drawing, annotations, measuring, upload, analysis, components, table, search and print tools. The DrillOps menu groups File, Edit, View and Help/account actions and includes searchable Quick actions. Drawing uses a crosshair; hold Shift to select features in the drawing layer, then release to resume the sketch. The drawing panel changes layer colour, opacity, width and line style, with optional horizontal-distance labels. Rectangles use two opposite corners. Manual routes are drawn lines; they do not snap to roads. URL uploads accept direct HTTPS links that allow cross-origin browser access, up to 50 MB, then open the normal import review.

Not connected yet

Travel-time areas and road-network routing require a routing service. QGIS integration and live Postgres, Databricks or ArcGIS source connectors are not implemented. No new external service or Supabase setting was added for these tools.
