Files, printing and current limits

FieldMaps is in development. These capabilities run in your browser; this update does not change the cloud account or storage settings.

Import formats

FormatSupport and qualifications
Shapefile.shp with its .shx, .dbf and usually .prj; select the parts together or upload an archive. Confirm the CRS if it is missing.
GeoJSON and sequences.geojson, .json; newline/record-separated .geojsonl, .geojsons, .geojsonseq, .jsonl and .ndjson.
GeoPackage and File GeodatabaseVector and raster .gpkg; zipped .gdb folders. Spatial datasets are reviewed separately and grouped. Mixed raster/vector containers and unusual proprietary geodatabase extensions are not comprehensively covered.
GeoParquet.parquet with GeoParquet metadata and WKB geometry, or a Parquet GEOMETRY/GEOGRAPHY column. GeoArrow-encoded geometry is not supported.
KML / KMZ / CAD.kml, .kmz and .dxf. CAD points, lines and shapes become separate editable layers. KML imagery overlays, tours, network links and original styles are not preserved.
ArcGIS packages.lpk, .lpkx, .mpk and .mpkx archives are unpacked to read supported embedded data. ArcGIS map layouts, styles, services and external references are not recreated.
OpenStreetMap and GPS.osm, .osm.pbf, .gpx, .tcx and .fit with recorded coordinates. Small extracts only. Direct .gpi import is not available; convert to GPX with GPSBabel first.
Raster dataGeoTIFF/COG (.tif/.tiff), raster GeoPackage, ASCII (.asc) and XYZ grids. PNG/JPEG with a world file (.pgw/.jgw/.wld) remain spatial rasters. Confirm source CRS when needed. Rasters are displayed using bounded previews, not a server-generated tile pyramid.
VRTIncluded source rasters or HTTPS source URLs that allow browser access (CORS). Sources are downloaded in the browser, up to 250 MB combined and 25 sources. Executable pixel functions are rejected.
Spreadsheets.xlsx, .xls, .xlsm, .numbers, .ods, .csv, .tsv, .psv and delimited .txt. Each populated sheet becomes a dataset. Place rows by coordinate columns or join them to an existing spatial layer using a unique match column. Macros are not executed.
Images and PDFsJPEG, PNG, WebP, GIF (still image), BMP, HEIC/HEIF, SVG and PDF. Files without world files become positioned image annotations. Adjust location, width and rotation in layer settings; use photo GPS coordinates when available. Each PDF page becomes an annotation (up to 25 pages). PDF map coordinates are not interpreted.
ArchivesZIP, 7z, RAR, TAR, GZ and TGZ. Maximum expanded batch size 300 MB, 5,000 entries per archive, and two nested archive levels. Encrypted archives are not supported.

Upload limits

Up to 25 files per selection; 300 MB per batch; 20,000 features or rows per dataset; 20 MB per image/PDF. Existing cloud storage still accepts at most 50 MB per file. The browser importer can read GeoTIFFs up to 250 MB in local testing. These are not Felt’s 100 GB limits.

Use drag-and-drop, Add data, or Cmd/Ctrl+U. Imports are reviewed before saving. Multi-sheet and multi-dataset inputs are grouped. Files with missing coordinates require a CRS or a join; there is no silent assumption that every file is latitude/longitude.

Image export

Sign in, then choose Export image or Shift+Cmd/Ctrl+E. Pan and zoom the preview; set width and height (96–9,600 pixels), 1×–4× resolution, PNG/JPG/PDF, editable SVG or Vector PDF, JPG quality, legend/title/description and metric/US scale bar. Move and resize the legend. Rotate the map clockwise or reset it with Point north. Exports include attribution and have an opaque background.

Print layouts

Choose Print layout or Cmd/Ctrl+P. Add pages; use A4, A3, Letter, 11×17 or custom 1–100 inch dimensions in portrait/landscape. Add movable, resizable maps, locators, legends, text, logos and background sections. Map views have independent extents and layer selection, clockwise rotation, north arrows and metric/US scale bars. Locator footprints follow the rotated map. Legends show categories, numeric ranges, point symbols/sizes, line styles and fallback values. Choose individual entries, rename their labels, show counts and adjust text size. Use Fit legend height to avoid clipped entries. Text accepts map-title, map-description and current-date tokens. Duplicate items with Cmd/Ctrl+D. Double-click a map to pan/zoom; Esc ends map editing.

Export the current page as PNG, JPG, raster PDF, editable SVG or Vector PDF. Use Export all pages as PDF to combine pages in sidebar order, preserving each page’s dimensions, with editable vectors or raster images. Vector formats preserve paths and text, including polygon holes; basemaps, uploaded imagery and image logos remain embedded raster images. Raster content uses the selected 150/300/600 DPI. Large exports are reduced to a maximum 16,384-pixel side and 32 megapixels, with the effective resolution shown. Third-party imagery must load successfully and permit browser export. Pages and reusable templates save in this browser, separately for each account/project; they are not shared across devices or a workspace.

Not implemented in this update

  • Direct Garmin GPI decoding; all proprietary ArcGIS features; GeoArrow-encoded Parquet.
  • Address/place-name geocoding, saved standalone non-spatial tables, spatial analysis and appending/combining layers.
  • A dedicated “Upload new version” flow that replaces a saved layer’s source file while retaining its identity and styling.
  • A general URL upload interface, QGIS plugin or external data-source connectors (XYZ tile links and browser-readable VRT sources are available).
  • 100 GB files, server processing or large-raster tiling.
  • Workspace-shared print templates and cloud-synced print pages. Rotation is available in print layouts and export previews; the main working map remains north-up.
  • Continuous gradient legend ramps and full Felt feature parity. Expression legends list actual displayed style combinations. Very large legends must be resized, split between legend boxes or filtered to fit. Text rendering in vector PDFs uses embedded Noto Sans; scripts outside that font’s coverage are not guaranteed.

QGIS project/style files, ArcGIS .lyr/.lyrx references, ECW, Word, PowerPoint and Illustrator source files are not imported as spatial data. Upload their underlying GIS data or an appropriate exported image/PDF.
