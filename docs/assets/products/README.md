# Public product imagery

These assets are actual interface captures, not generated product mockups.

- `fieldops-map.png`: original FieldOps App Store capture, `Screenshots/iPhone-6.9/02-dxf-map.png`. Includes a sample control-point drawing.
- `fieldops-navigation.png`: original FieldOps App Store capture, `Screenshots/Build17/iPhone-6.9/04-waypoint-navigation.png`. Includes a sample navigation destination.
- `fieldmaps-iphone.png`: FieldMaps 2.0 App Store screenshot, `drillops-viewer/AppStore/Screenshots/iphone-map.png`.
- `fieldmaps-web.png`: existing actual web workspace capture, `fieldops-maps-live.png`, showing the empty import workspace.
- `activities-dar.png`: browser capture of the real `docs/field.html` DAR form. Rendered in an isolated static page with its original styles, no scripts, no credentials and no project data. The dialog was opened for the capture; its fields and labels were not redesigned or populated. The temporary capture page was removed.
- `fieldops-app-store-qr.png`: generated QR for `https://apps.apple.com/au/app/fieldops-by-drillops/id6797079076`; independently decoded using Apple Vision to verify the destination.

Screenshots show the interfaces at the time of capture. Captions identify sample data or empty states. Do not replace them with invented maps, app interfaces or generated scenery.
